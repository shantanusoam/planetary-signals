# Contributing

Thanks for helping make planetary data more legible.

1. Open an issue describing the provider, public value, access method and licence.
2. Keep each pull request focused on one adapter or one coherent interface change.
3. Run `npm test` before requesting review.
4. Include loading, empty, partial and error behaviour for user-facing changes.
5. Never commit credentials, redistribute restricted data or expose precise sensitive-species locations.

Read [the adapter guide](docs/adding-an-adapter.md) before connecting a new provider.
